Stabilized Camera Perspective (2.5D View in a 3D World)

While the platforms, sky environment, and character are constructed in full 3D coordinate space, the camera viewpoint is locked to a stabilized tracking plane. Mouse camera control is disabled by design, ensuring that players never struggle with camera angles and can focus entirely on spatial judgment and jump timing. Pressing the P key smoothly cycles through predefined viewing angles (Behind Character, Front View, and Overhead View).

Key Technical Concepts Explained

Translating complex game development terminology into clear, accessible concepts.

3D Design & Modeling

Blender & Polygon Optimization

Blender is professional software used to design 3D models. To make platforms run smoothly on basic computers, models underwent retopology—a process of reducing the number of geometric polygons while keeping the shape visually identical.

Visual Programming

Blueprint Visual Scripting

Instead of typing thousands of lines of code syntax, Unreal Engine allows programming using visual logic blocks. This was used to program player jumping, gravity triggers, platform movement, and camera viewpoint switching.

Hardware Performance

Integrated Graphics (iGPU)

Most school laptops do not have expensive dedicated gaming cards; they rely on integrated graphics built directly into the main processor. Rush Parkour was specifically calibrated to achieve a smooth 60+ FPS on these everyday machines.

Physics Simulation

Reactive Crumbling Platforms

Platforms remain stable until the character steps on them. A delayed timer then awakens real-time gravity physics, causing the platform to drop away into the void, testing the player's reaction time and speed.

Automated Navigation

Enemy Pathfinding (NavMesh)

Obstacles patrol platforms automatically using mathematical pathfinding meshes. They calculate walkable boundaries so they do not fall off edges and actively pace back and forth to create dynamic jump hazards.

Memory Management

Level of Detail (LOD) & Caching

As platforms get further from the camera, the computer automatically swaps them for simpler 3D representations. Combined with loading assets into computer memory at startup, this prevents game stuttering and keeps file sizes small.
