Technical Implementation

How the interactive world was built using accessible technology.

Focused Camera System

While the environment is fully 3D, the player's view is locked to a specific tracking angle.

The mouse does NOT control the camera. Players use the P key to cycle through predefined viewpoints (Front, Behind, Overhead). This reduces complexity and allows the user to focus entirely on movement and timing.

3D Environment Creation

The world consists of geometric platforms suspended in an open sky. To ensure smooth performance, all 3D models were optimized in Blender (a 3D design software) to reduce their complexity without losing visual quality.

Physics & Interaction

The project uses a physics engine to simulate real-world gravity. Some platforms remain solid, while others are programmed to react and fall away the moment they are touched, testing the user's reaction time.

Computer-Controlled Obstacles

Obstacles and enemies move independently using Pathfinding Algorithms. They can detect the user and calculate routes across the 3D platforms, adding dynamic challenges to the environment.
